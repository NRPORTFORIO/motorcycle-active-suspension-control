# 2輪車用電子制御サスペンション（EERA想定）ECUシミュレータ ＆ 走行データ自動解析ツール

## 📌 プロジェクト概要
本プロジェクトは、「2輪車向けデバイス（EERA等）の先行開発、検証、テスト、実車での評価」の業務を深くイメージし、AI共創のもと作成したポートフォリオです。

「車載ECUによるリアルタイムの減衰力制御（C言語）」と、テストコース走行後の「実験ログデータ自動合否判定（Python）」の2つのシステムを連携させ、開発から評価・解析にいたる一連の技術サイクルを再現しています。

---

## 🛠️ システム構成と実装内容

### 1. 車載ECU制御シミュレータ（C言語）
* **ファイル名:**`ecu_suspension_control.c`
* **実装内容:** 
  * 走行中の路面衝撃（Gフォース）をセンサーから検知し、瞬時に減衰力を3段階（ソフト／ミディアム／ハード）に自動調整するロジックを実装。
  * 2輪車開発において最重要となる安全思想（フェイルセーフ機能）を組み込み、センサーに異常値が入力された際は即座に安全モード（ミディアム固定）へと移行するプログラムを構造体と条件分岐で表現。

### 2. 走行データ自動評価・解析スクリプト（Python）
* **ファイル名:** `analyze_suspension_log.py`
* **実装内容:** 
  * テストコースを走行した実車から出力される膨大な走行ログ（CSVデータ）の解析を自動化。
  * `pandas` ライブラリを活用し、最大衝撃値（Max-G）の自動抽出や、車載ECUのフェイルセーフ機能が10ms単位のログ内で正しく作動しているかの「PASS/FAIL自動合否判定」を実装。

---

## 概要・苦戦・工夫
**○ 概要**： 先行開発・実車評価を想定したECU挙動の再現と、走行データの自動解析ツールの構築。
**○【苦戦した点】**： テストコース走行後に実車から吐き出される、10ms単位の膨大な走行ログ（CSV）の解析自動化です。当初はデータの抽出方法に苦戦しましたが、PythonのpandasライブラリをAI共創のもと、最大衝撃値（Max-G）の自動抽出に成功しました。
**○【工夫した点】**： 単にログをグラフ化するだけでなく、法規や社内基準を満たしているかをシステム側で自動演算し、ログから 【PASS】 / 【FAIL】 を自動合否判定する仕組みを創った点です。評価・テスト業務の本質である「客観的な適合評価」を意識して構築しました。
